# Развёртывание формы Bitrix24

## Что подготовлено

- Публичный клиент: `https://parkskazka.ru/snow-mail/`
- Endpoint: `https://parkskazka.ru/snow-mail/api/lead`
- Серверный код: `api/_bootstrap.php` и `api/lead/index.php`
- Секретная переменная: `BITRIX_WEBHOOK_URL`

## Границы безопасности

- URL входящего webhook Bitrix24 задаётся только в окружении PHP-FPM
- Файл с секретом не размещается в web root и не добавляется в Git
- Логи содержат только время, request ID, статус, HTTP-код и ID созданного лида
- Рабочая CRM не используется в автоматических тестах

## Порядок публикации

1. Подтвердить web root `/var/www/parkskazka.ru/snow-mail` на основном сервере `parkskazka-main` и способ передачи переменных в PHP-FPM
2. Разместить папку `api` так, чтобы `POST /snow-mail/api/lead` выполнял `api/lead/index.php`
3. Создать закрытую директорию для `LEAD_STORAGE_DIR` и `LEAD_LOG_PATH`, доступную пользователю PHP-FPM
4. Задать `BITRIX_WEBHOOK_URL` как базовый URL входящего webhook без имени REST-метода
5. Проверить PHP-синтаксис, CORS preflight, отклонение неверного Origin, валидацию и mock Bitrix24
6. Выполнить один явно помеченный тестовый лид с тестовыми UTM и подтвердить поля в Bitrix24
7. После успешной проверки опубликовать клиентские изменения GitHub Pages
8. Проверить реальную форму с мобильного и desktop, затем удалить тестовый лид по согласованной процедуре

Публикация не выполняется автоматически и требует отдельной команды.

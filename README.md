# «Снежная почта» — локальный лендинг

Статический адаптивный прототип без публикации.

## Запуск

```powershell
cd C:\Users\asmaga\Documents\Skazka\snow-mail-landing
python -m http.server 8080
```

Открыть `http://127.0.0.1:8080/`.

Автотест `tests/qa_landing.py` использует отдельный локальный порт `8091`. Если порт занят, адрес можно переопределить через `SNOW_MAIL_BASE_URL`.

## Форма

По умолчанию форма работает в честном демо-режиме: валидирует поля, сохраняет последнюю заявку локально и показывает результат. Для production нужно указать HTTPS endpoint в `config.js` и переключить `demoMode` после проверки CRM/API.

Endpoint должен принимать JSON с полями `name`, `phone`, `date`, `children`, `age`, `comment`, `consent`, UTM, `page_url` и `referrer`.

## Границы релиза

- Публикация выполняется через GitHub Pages из ветки `main`.
- Изображения сгенерированы как нейтральные постановочные сцены; они не изображают реальные аттракционы или территорию Парка Сказка.
- Перед рекламным запуском нужно подключить форму к CRM и повторно проверить endpoint.
